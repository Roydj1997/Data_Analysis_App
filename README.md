Data Analysis App (Using Streamlit)
📊 Overview

The Data Analysis App is an interactive web application built using Python and Streamlit that allows users to perform Exploratory Data Analysis (EDA) on any CSV dataset without writing code.

The application automatically detects numerical and categorical columns and provides multiple visualization techniques to understand the dataset efficiently.
